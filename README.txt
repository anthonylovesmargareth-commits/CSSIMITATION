BASIC WEB DESIGN — 5.4 IMITATION ASSIGNMENT

Files:
- index.html: the webpage with all six projects
- style.css: CSS3 image effects
- seven original image files: used by the webpage

To publish:
1. Create or open your GitHub repository.
2. Upload index.html, style.css, and all seven image files into the same repository folder.
3. Commit the files.
4. In the repository, open Settings > Pages.
5. Choose Deploy from a branch, select the main branch and / (root), then save.
6. Open the published Pages URL and submit that URL to your teacher.

Keep the image filenames exactly as they are. The HTML references them by filename.
